Cloud Security Sandbox

Learn cloud security by breaking it.

A practice range for the CCSP domains, built for people who learn by doing. Each mission puts you in a broken cloud environment: a misconfigured network, an exposed database, a risky pull request, a live incident, a contract decision. Change the settings, run the simulation, and see which attacks get through and what breaks for the business.

How these are built

Each training follows one exam or discipline, so the missions map to what you would be tested on. I design the scenarios with Claude, play through every mission myself, and keep the companies, keys and logs fictional so you can break things without breaking anything real.

Your progress is saved in your own browser. Nothing connects to a real cloud or sends data anywhere. More sandboxes for other security domains are on the way. If there's one you'd like to see, get in touch.
